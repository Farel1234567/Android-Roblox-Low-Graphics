Script untuk membantu mengurangi efek visual pada experience Roblox milikmu.

⚡ Low Graphics Script

Tekan tombol di bawah untuk menyalin script Lua.

local Lighting = game:GetService("Lighting")

Lighting.GlobalShadows = false

for _, obj in ipairs(game:GetDescendants()) do
    if obj:IsA("PostEffect") then
        obj.Enabled = false
    elseif obj:IsA("ParticleEmitter")
        or obj:IsA("Trail")
        or obj:IsA("Beam") then
        obj.Enabled = false
    end
end

print("Low Graphics enabled!")

📱 Cara menggunakan

1. Salin script di atas.

2. Buka Roblox Studio dan proyek milikmu.

3. Buat sebuah LocalScript di StarterPlayer → StarterPlayerScripts.

4. Tempelkan script, lalu jalankan untuk menguji hasilnya.

Catatan: Script ini ditujukan untuk experience yang kamu buat atau punya izin untuk edit. Efek pengurangan grafis dapat berbeda-beda dan tidak menjamin peningkatan FPS.
